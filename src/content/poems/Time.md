# Time
Where
When and how
Does it begin, did it begin
The time

Did it begin, in hell
Underground — deep
In heart — mind
And excavation 
Would reveal it

Did it begin, in heaven
Far — above
In cosmos, skies
Beyond sight
And flight
Would show it

Deep nor beyond
If found standing
Nowhere must
It begin

Never
Must be when
Time, it cannot be
